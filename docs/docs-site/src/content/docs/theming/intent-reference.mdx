## IdentityIntent

Configures brand anchors and color synthesis behavior:

| Field | Type | Default | Contract |
| :--- | :--- | :--- | :--- |
| **`brandColor`** | `ColorSpec?` | `null` | Primary brand color. Intake accepts `Hex`, `Argb`, or `Hsl`. |
| **`presence`** | `BrandPresence?` | `Balanced` | Tint prominence: `Subtle`, `Balanced`, `Strong`, or `Dominant`. |
| **`supportingColors`** | `List<ColorSpec>` | `emptyList()` | Secondary brand anchors. Maximum 3 honored; extras are rejected. |
| **`typography`** | `TypographyIdentity?` | `null` | Brand typeface candidates, role pins, or fallback stacks. |
| **`deriveColors`** | `Boolean` | `true` | When `true`, palette is synthesized from brand, mood, and domain signals. |

When `brandColor` is `null`:
- If `deriveColors = true` (default), Basis synthesizes a neutral palette informed by your mood and domain signals.
- If `deriveColors = false`, Basis produces a fully achromatic theme (`chroma = 0.0`), delivering neutral grays across all token roles.
