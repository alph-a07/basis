## 2. Configure Brand Presence

The `presence` parameter determines how prominently your brand hue tints surfaces and components:

| Presence | Behavior |
| :--- | :--- |
| **`BrandPresence.Subtle`** | Brand color reaches selection highlights, focus indicators, and gradient accents only. Surfaces remain neutral. |
| **`BrandPresence.Balanced`** | *(Default)* Subtle surface treatments with brand fills applied to primary calls to action. |
| **`BrandPresence.Strong`** | Balanced rules plus elevated surface tint and stronger active borders. |
| **`BrandPresence.Dominant`** | Balanced rules plus a noticeable brand tint across default surface backgrounds. |

## 3. Omitting Brand Color

When `brandColor` is `null`:

- **`deriveColors = true`** *(default)*: Basis synthesizes a neutral palette informed by your mood and domain signals.
- **`deriveColors = false`**: Basis produces a fully achromatic theme (`chroma = 0.0`), delivering neutral grays across all token roles.

## 4. Supporting Colors and Color Intake

Specify secondary anchors using `supportingColors` (up to 3 are honored; extras are rejected during normalization).

Colors are supplied using `ColorSpec`:

- **`ColorSpec.Hex(value)`**: Hex string with or without leading `#`, e.g. `"#0284C7"`.
- **`ColorSpec.Argb(argb)`**: Packed 32-bit integer in `0xAARRGGBB` format.
- **`ColorSpec.Hsl(h, s, l, a)`**: Hue in degrees (0–360), saturation and lightness in 0–1.

## Verify the Result

Run your app in the emulator or preview. Press Tab or use keyboard navigation to focus an interactive button.

You should see a focus ring using `BasisTheme.colors.focus.ring` anchored to your brand hue, maintaining a ≥ 3:1 contrast ratio against the background surface:
