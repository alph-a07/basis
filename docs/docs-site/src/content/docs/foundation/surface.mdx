`Surface` is the visual foundation of your application. Every card, dialog, bottom sheet, and list item is built upon a surface that coordinates background fill, corner shape, border hairlines, and content colors.

In Basis, surface styling is provided via the `Modifier.basisSurface()` modifier.

## Tonal Elevation and Surface Roles

Rather than using flat white or arbitrary gray backgrounds, Basis organizes surfaces into semantic levels that adapt cleanly across light and dark modes:

| Surface Token | Purpose | Light Mode Behavior | Dark Mode Behavior |
| :--- | :--- | :--- | :--- |
| **`surface`** | Main background canvas | Crisp white or soft off-white | Deep, comfortable dark background |
| **`surfaceElevated`** | Cards, list tiles, top bars | Subtle ambient drop shadow | Lighter tonal lightness step |
| **`surfaceSunken`** | Inset input fields, code blocks | Recessed gray tone | Darker recessed container |
| **`surfaceOverlay`** | Dialogs, menus, modal sheets | Prominent drop shadow | Highest lightness surface step |
| **`surfaceInverse`** | Snackbars, high-contrast tooltips | High-contrast dark tone | High-contrast light tone |

## Surface Styling with `Modifier.basisSurface()`

When building custom layouts where you already have a `Box` or `Row`, apply the `basisSurface` modifier directly to apply corner clipping, background fill, hairline borders, and elevation depth:

```kotlin
import androidx.compose.foundation.BorderStroke
import androidx.compose.foundation.layout.Box
import androidx.compose.foundation.layout.Column
import androidx.compose.foundation.layout.padding
import androidx.compose.material3.Text
import androidx.compose.runtime.Composable
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import io.github.alph_a07.basis.components.foundation.modifier.basisSurface
import io.github.alph_a07.basis.components.theme.BasisTheme

@Composable
fun OrderCard() {
    Box(
        modifier = Modifier
            .basisSurface(
                shape = BasisTheme.shapes.medium,
                color = BasisTheme.colors.surfaceElevated,
                depth = BasisTheme.depth.level1
            )
            .padding(BasisTheme.spacing.md)
    ) {
        Column {
            Text(
                text = "Order Details",
                style = BasisTheme.typography.titleMedium,
                color = BasisTheme.colors.onSurface
            )
            Text(
                text = "Delivered on Thursday",
                style = BasisTheme.typography.bodySmall,
                color = BasisTheme.colors.onSurfaceVariant
            )
        }
    }
}
```

## Hairline Borders and Accents

You can pair `basisSurface` with a `BorderStroke` to define subtle element boundaries:

```kotlin
import androidx.compose.foundation.BorderStroke
import androidx.compose.foundation.layout.Box
import androidx.compose.foundation.layout.padding
import androidx.compose.material3.Text
import androidx.compose.runtime.Composable
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import io.github.alph_a07.basis.components.foundation.modifier.basisSurface
import io.github.alph_a07.basis.components.theme.BasisTheme

@Composable
fun StatusBadge(label: String) {
    Box(
        modifier = Modifier
            .basisSurface(
                shape = BasisTheme.shapes.small,
                color = BasisTheme.colors.surfaceVariant,
                border = BorderStroke(1.dp, BasisTheme.colors.outlineVariant)
            )
            .padding(
                horizontal = BasisTheme.spacing.sm,
                vertical = BasisTheme.spacing.xxs
            )
    ) {
        Text(
            text = label,
            style = BasisTheme.typography.labelSmall,
            color = BasisTheme.colors.onSurfaceVariant
        )
    }
}
```

## Best Practices

- **Use semantic surfaces for hierarchy**: Reserve `surfaceOverlay` for floating modals and menus, `surfaceElevated` for cards, and `surface` for the root scaffold.
- **Rely on `outlineVariant` for hairlines**: When adding card borders, use `BasisTheme.colors.outlineVariant` for a subtle, accessible boundary that adapts between light and dark modes.
- **Pair with `Modifier.basisMinTouchTarget()` on interactive surfaces**: If the surface is clickable, ensure it satisfies the 48dp touch target requirement.
