## Focus Rings

The `Focusable` foundation atom standardizes focus indicator styling across all interactive composables:
- Uses `--docs-focus-ring` (and `--d-color-focus-ring`) with an explicit 2px offset.
- Enforces high contrast against adjacent surfaces in light and dark modes.

## Keyboard Support

Ensures consistent Tab navigation order, hardware keyboard traversal, and accessibility service announcements.
