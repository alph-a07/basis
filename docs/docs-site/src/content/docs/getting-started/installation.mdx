Integrating Basis into an Android application requires configuring your Gradle repositories, declaring the required dependencies, and optionally configuring the `basis-lint` static analysis rules.

## Requirements

Before adding Basis, verify that your project environment satisfies these minimum requirements:

| Environment | Minimum Version | Recommended |
| :--- | :--- | :--- |
| **JDK** | 17 | JDK 21 |
| **Android Gradle Plugin (AGP)** | 8.5.0 | 8.8.0+ |
| **Kotlin** | 2.0.0 | 2.1.0+ |
| **Compose Compiler Plugin** | 2.0.0 | Matching Kotlin version |
| **Android SDK** | `compileSdk 37`, `minSdk 24` | `targetSdk 36` |

## Repository Setup

Add Maven Central to your `settings.gradle.kts` under `dependencyResolutionManagement`:

```kotlin
// settings.gradle.kts
dependencyResolutionManagement {
    repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS)
    repositories {
        google()
        mavenCentral()
    }
}
```

## Adding Dependencies

Basis is divided into two primary artifacts for client applications:

- **`basis-components`**: Android Jetpack Compose composables, foundation modifiers, and ambient locals.
- **`basis-theme`**: Token models, intent definitions, and theme resolution pipeline.

Add the artifacts to your module's `build.gradle.kts`:

```kotlin
// app/build.gradle.kts
plugins {
    alias(libs.plugins.android.application)
    alias(libs.plugins.kotlin.android)
    alias(libs.plugins.kotlin.compose)
}

android {
    namespace = "com.example.app"
    compileSdk = 37

    defaultConfig {
        applicationId = "com.example.app"
        minSdk = 24
        targetSdk = 36
        versionCode = 1
        versionName = "1.0"
    }

    buildFeatures {
        compose = true
    }
}

dependencies {
    // Basis Design System
    val basisVersion = "0.2.0"
    implementation("io.github.alph-a07:basis-components:$basisVersion")
    implementation("io.github.alph-a07:basis-theme:$basisVersion")

    // Jetpack Compose Foundation
    implementation(platform("androidx.compose:compose-bom:2024.12.01"))
    implementation("androidx.compose.ui:ui")
    implementation("androidx.compose.foundation:foundation")
    implementation("androidx.compose.material3:material3")
}
```

## Static Analysis with `basis-lint`

To prevent design system drift and ensure consistent token usage, add `basis-lint` rules to your Detekt configuration:

```kotlin
// build.gradle.kts
dependencies {
    detektPlugins("io.github.alph-a07:basis-lint:0.2.0")
}
```

In your `config/detekt/detekt.yml`:

```yaml
basis:
  NoHardcodedColors:
    active: true
    excludes: ['**/theme/core/**']
  EnforceTokenUsage:
    active: true
  TouchTargetFloors:
    active: true
```

## ProGuard & R8 Configuration

Basis is designed to be entirely reflection-free. All token classes and style patches are standard Kotlin data classes. If your application applies full R8 optimization, keep the token structures for serialization or obfuscation safety:

```properties
# proguard-rules.pro
-keepclassmembers class io.github.alph_a07.basis.theme.tokens.** {
    <fields>;
    <methods>;
}

-keepclassmembers class io.github.alph_a07.basis.theme.intent.** {
    <fields>;
    <methods>;
}
```

## Verification

Once dependencies are synced, verify that your build resolves all artifacts and compiles cleanly:

```bash
./gradlew assembleDebug
```

With dependencies installed, proceed to the [Quickstart](/docs/getting-started/quickstart) guide to configure your root `BasisTheme`.
