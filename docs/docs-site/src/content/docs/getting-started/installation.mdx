Add three Gradle dependencies and you are ready to call `BasisTheme`. This page covers tool requirements, repository setup, and the ProGuard posture.

## Requirements

| Tool | Minimum Version | Notes |
| :--- | :--- | :--- |
| **JDK** | 17 | JDK 21 recommended |
| **Android Gradle Plugin (AGP)** | 8.8.0 | Compatible with Gradle 8.11+ / 9.2+ |
| **Kotlin** | 2.0.0 | Compatible with Kotlin 2.1+ and Compose Compiler |
| **Android SDK** | `minSdk 24`, `compileSdk 37` | `targetSdk 36` (see [Platform Compatibility](/docs/getting-started/compatibility)) |

## Repository Setup

Ensure `mavenCentral()` is declared in your root `settings.gradle.kts`:

```kotlin
// settings.gradle.kts
dependencyResolutionManagement {
    repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS)
    repositories {
        google()
        mavenCentral()
    }
}
```

## Adding Dependencies

Basis publishes three artifacts:

- **`basis-components`**: Jetpack Compose foundation modifiers (`basisSurface`, `basisClickable`, `basisFocusRing`, `basisPadding`, etc.) and theme ambient locals.
- **`basis-theme`**: Pure Kotlin multiplatform resolution engine that converts `BasisIntent` into typed token trees.
- **`basis-lint`**: Android Lint check (`SpOnlyFontSizeDetector`) enforcing `sp` units for font size, line height, and letter spacing.

## ProGuard and R8

Basis uses no reflection. All token structures and modifiers are pure Kotlin classes. Verified with a full-mode R8 release build of `demo-app` without requiring custom `-keep` rules.

## Verify the Installation

Compile the debug variant from your terminal:

```bash
./gradlew assembleDebug
```

You should see `BUILD SUCCESSFUL`. The compiler resolves `BasisTheme` and registers the `basis-lint` typography check in your build pipeline.
