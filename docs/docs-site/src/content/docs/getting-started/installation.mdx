Add Basis dependencies to your Gradle build scripts to access foundation modifiers, token resolution, and build-time lint enforcement in your Android app.

## Requirements

Ensure your build environment meets the following baseline tool versions:

| Tool | Minimum Version | Notes |
| :--- | :--- | :--- |
| **JDK** | 17 | JDK 21 recommended |
| **Android Gradle Plugin (AGP)** | 8.8.0 | Compatible with Gradle 8.11+ / 9.2+ |
| **Kotlin** | 2.0.0 | Compatible with Kotlin 2.1+ and Compose Compiler |
| **Android SDK** | `minSdk 24`, `compileSdk 37` | Target SDK `targetSdk 36` |

## Repository Setup

Ensure `mavenCentral()` is declared in your root `settings.gradle.kts`:

```kotlin
// settings.gradle.kts
dependencyResolutionManagement {
    repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS)
    repositories {
        google()
        mavenCentral()
    }
}
```

## Adding Dependencies

Basis publishes three artifacts:

- **`basis-components`**: Jetpack Compose foundation modifiers (`basisSurface`, `basisMinTouchTarget`, `basisClickable`) and theme ambient locals.
- **`basis-theme`**: Pure Kotlin multiplatform resolution engine that converts `BasisIntent` into typed token trees.
- **`basis-lint`**: Android Lint checks enforcing typography units (`sp` only for font size, line height, and letter spacing) at build time.

## ProGuard and R8

Basis relies on zero reflection. All token structures and modifiers are pure Kotlin classes. Verified with a full-mode R8 release build of `demo-app` without requiring custom `-keep` rules.

## Verify the Installation

Compile the debug variant from your terminal:

```bash
./gradlew assembleDebug
```

You should see `BUILD SUCCESSFUL`. The compiler resolves `BasisTheme` and registers `basis-lint` checks in your build pipeline.
