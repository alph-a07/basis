## Gradle Setup

Configure the Basis Maven repository and convention plugins in your `settings.gradle.kts` and `build.gradle.kts`.

## Dependencies

Add the Basis components and theming runtime to your Android module dependencies:

- `io.github.alph-a07:basis-components`
- `io.github.alph-a07:basis-theme`

## Verification

Run `./gradlew check` to verify that all dependencies and convention checks pass without conflicts.
