## Binary Compatibility & Public API Stability (BCV)

Basis uses the **JetBrains Binary Compatibility Validator (BCV)** (`org.jetbrains.kotlinx.binary-compatibility-validator`) to protect public API signatures from breaking changes:

- **Committed Contract:** Every public signature is tracked in `basis-components/api/basis-components.api`.
- **Zero Breaking Changes Policy:** Every build and pull request executes `./gradlew releaseApiCheck` in CI. Any uncommitted addition, deletion, or binary signature alteration immediately fails the build.
- **Explicit API Mode:** Kotlin's `explicitApi()` mode is enabled across `basis-components`, enforcing explicit visibility modifiers and complete KDoc documentation on every public symbol.
- **Foundation Scope:** Covers the public `BasisTheme` theme entrypoints, all 13 foundation modifiers (`basisBorder`, `basisClickable`, `basisClip`, `basisFocusRing`, `basisFocusable`, `basisIndication`, `basisPadding`, `basisRipple`, `basisSelectable`, `basisShadow`, `basisTouchTarget`, `basisModifier`, `basisClearAndSetSemantics`), and theme contracts.

## Performance SLAs & Baseline Profile

Basis enforces strict frame rendering budgets to ensure seamless 60 Hz and 120 Hz display performance:

### Frame Timing Budgets

| Target Display Refresh Rate | Frame Rendering Budget | SLA Threshold | Verification Test |
| :---: | :---: | :---: | :--- |
| **60 Hz Standard Displays** | **16.6 ms** | P95 `< 16.6 ms` | `BasisStartupBenchmark` with `FrameTimingMetric` |
| **120 Hz High-Refresh Displays** | **8.3 ms** | P99 `< 8.3 ms` | `BasisStartupBenchmark` with `FrameTimingMetric` |

### Pre-compiled ART Baseline Profile

Every release of Basis ships with a pre-compiled **ART Baseline Profile** embedded directly in the library AAR (`basis-components/src/main/baseline-prof.txt`):

1. **Zero Install JIT Jank:** Android's Ahead-Of-Time (AOT) compiler pre-compiles Basis theme locals, modifier chains, and token resolution algorithms during application installation via Google Play Cloud Profiles.
2. **Cold Startup Optimization:** Eliminates runtime interpretation of core composable paths during the critical first application launch frame.
3. **Continuous Regeneration:** Updated and verified using the `:basis-baseline-profile` generator module on connected Android reference devices.
