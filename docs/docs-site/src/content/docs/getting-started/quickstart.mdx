Wrap your app root with `BasisTheme`, use `basisSurface` on containers, and call `BasisButton` for interactive targets. You get semantic tokens, verified contrast, and 48dp touch targets without any additional configuration.

## 1. Wrap Your Hierarchy in BasisTheme

Place `BasisTheme` at the root of your Compose hierarchy. It provides ambient token locals for colors, typography, spacing, corner radii, and depth down the composition tree:

## 2. Access Semantic Tokens

Read resolved tokens directly through `BasisTheme`:

```kotlin
Modifier.basisSurface(
    shape = RoundedCornerShape(BasisTheme.radius.level2.toDp()),
    color = BasisTheme.colors.surface.elevated,
)
```

## 3. Apply Foundation Modifiers

Basis foundation modifiers bind layouts to theme tokens:

- **`Modifier.basisSurface(shape, color)`**: Clips, colors, and applies depth shadows matching theme tokens.
- **`Modifier.basisMinTouchTarget()`**: Enforces a 48dp minimum touch target bounding box.
- **`Modifier.basisClickable(onClick)`**: Attaches accessible click semantics, focus ring, and interaction indication.

Explore all 13 atomic modifiers (including `basisBorder`, `basisClip`, `basisFocusRing`, `basisFocusable`, `basisIndication`, `basisPadding`, `basisSelectable`, and `basisToggleable`) in the [Foundation Modifiers catalog](/docs/modifiers/basis-surface).

## Verify the Result

Run your app in an emulator or open the `@Preview` in Android Studio.

You should see an elevated container displaying "Welcome to Basis" and a "Get Started" button styled with your brand fill, 8dp corner radius, and a 48dp minimum touch target — with no additional theme configuration.
