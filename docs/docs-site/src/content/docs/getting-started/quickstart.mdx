## Theme Wrapper

Wrap your root application composable with `BasisTheme` to initialize the design system tokens and environment:

```kotlin
BasisTheme {
    MainScreen()
}
```

## First Component

Render a `BasisButton` or `BasisDivider` to verify token inheritance and theme application.

## Observing Tokens

Components automatically inherit colors, shapes, and motion tokens based on the active theme mode.
