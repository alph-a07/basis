## 1. Wrap Your Hierarchy in BasisTheme

Place `BasisTheme` at the root of your Compose hierarchy. This provides ambient token locals for colors, typography, spacing, corner radii, and depth down the composition tree:

<DocSnippet name="quickstart_app" />

## 2. Access Semantic Tokens

Access resolved tokens directly through `BasisTheme`:

```kotlin
Modifier.basisSurface(
    shape = RoundedCornerShape(BasisTheme.radius.level2.toDp()),
    color = BasisTheme.colors.surface.elevated,
)
```

## 3. Apply Foundation Modifiers

Basis foundation modifiers bind component layouts to theme tokens:

- **`Modifier.basisSurface(shape, color)`**: Clips, colors, and applies depth shadows matching theme tokens.
- **`Modifier.basisMinTouchTarget()`**: Enforces a 48dp minimum accessible touch target bounding box.
- **`Modifier.basisClickable(onClick)`**: Attaches accessible click semantics and interaction indication.

## Verify the Result

Run your app in the Android emulator or inspect your `@Preview` composable in Android Studio.

You should see an elevated container displaying "Welcome to Basis" and a primary "Get Started" action button styled with your brand fill, 8dp corner radius, and a 48dp minimum touch target.
