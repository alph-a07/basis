# Interactive Node Guidance

BasisInteractiveNode centralizes shared click, select, and toggle interaction wiring, accessibility semantics, and touch target constraints across the design system.

## Accessibility

BasisInteractiveNode enforces WCAG 2.1 touch target floors (minimum 48dp physical target) and provides built-in keyboard navigation (Enter and Space key activation). Semantics roles and state properties (disabled, selected, toggleable) are automatically registered for screen readers.
