---
id: button
guidelines:
  do:
    - Use clear and action-oriented labels like "Submit" or "Save Changes".
    - Prefer primary prominence for the single main action per screen.
  dont:
    - Do not place multiple high-prominence buttons adjacent to one another.
    - Do not use vague labels such as "Click Here".
  notes:
    - Buttons expand automatically to meet 48dp touch target floors via BasisTouchTarget.
---

# Button Design Guidance

Buttons communicate actions users can trigger. They are categorized by visual prominence and interaction state.

## Accessibility

The button composable assigns Compose `Role.Button` and sets `semantics { onClick = ... }`.
Screen readers announce the button label followed by its role. Focus rings adhere to high contrast
requirements across light and dark themes.
