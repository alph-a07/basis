# Indication Guidance

BasisIndication produces theme-derived press, hover, and focus highlights conforming to active brand and contrast rules.

## Accessibility

BasisIndication ensures visual state feedback satisfies WCAG 2.1 non-text contrast requirements (minimum 3:1 contrast against adjacent background colors).
Highlights adapt when reduced motion is requested by avoiding spring expansion and fading opacity smoothly.
